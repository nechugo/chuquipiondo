# languages/

Carpeta de traducciones del tema nechugo News (text domain: `nechugo-news`).

Coloca aqui los archivos `.po` / `.mo` generados, por ejemplo:

- es_PE.po / es_PE.mo
- \`nechugo-news-es_PE.po\` tambien es valido.

Cadena de herramientas sugeridas: Poedit o WP-CLI:

\`\`\`bash
wp i18n make-pot . languages/nechugo-news.pot
\`\`\`\`

Git no versiona carpetas vacias; este README mantiene la carpeta en el repositorio.
