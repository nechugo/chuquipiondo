# CHUQUIPIONDO Child Theme

Tema hijo de **CHUQUIPIONDO** para personalizaciones seguras. Hereda toda la funcionalidad del tema padre.

## Instalación

1. Sube `chuquipiondo-child.zip` a **Apariencia > Temas > Añadir nuevo > Subir tema**.
2. Activa el tema **CHUQUIPIONDO Child**.

## Personalización

- Edita `style.css` para sobrescribir estilos del padre.
- Edita `functions.php` para agregar o sobrescribir funcionalidad.
- Ejemplos comentados incluidos en `functions.php`.

## Estructura

```
chuquipiondo-child/
├── style.css       # Cabecera + sobrescrituras CSS
├── functions.php   # Encola estilos + ejemplos de hooks
└── README.md       # Este archivo
```
