# CHUQUIPIONDO

**Tema WordPress profesional** para [www.chuquipiondo.com](https://www.chuquipiondo.com) — Liderazgo, Gestión y Formación con propósito. ¡Juntos, sí podemos!

## Entregables

Este repositorio contiene el tema WordPress **CHUQUIPIONDO** completo:

- **`chuquipiondo-theme/`** — Tema padre (instalar y activar).
- **`chuquipiondo-child/`** — Tema hijo (para personalizaciones seguras).

- **`chuquipiondo-ai-studio/`** — Plugin de IA para editar Entradas/Paginas (textos, codigo HTML/PHP/JS, imagenes 500x900) y publicar articulos con SEO.

Para instalar, comprime cada carpeta en un `.zip` y súbelo desde **Apariencia > Temas > Añadir nuevo > Subir tema**, o copia las carpetas a `wp-content/themes/`.

## Características principales

- **Ecosistema digital:** portal editorial + revista digital + plataforma musical.
- **Customizer completo:** 12 secciones, 6 presets de color, 165+ opciones.
- **3 filas de cabecera** configurables con cajas multiuso.
- **Hero / Slider** con master switch, 6 modos, 3 efectos, slides administrables.
- **Home Builder** modular (8 módulos, reordenables).
- **Blog editorial:** 5 estilos de tarjeta, grid configurable, sidebar flexible.
- **Single post:** 4 layouts, toggles de elementos, Post End Extension Area.
- **Publicidad:** 30+ slots, master switch, 5 modos, inserción inteligente en párrafos.
- **Social share** + **WhatsApp flotante** (9 posiciones, respeta reduced-motion).
- **Música:** CPT `musica`, reproductor HTML5, mini player sticky, descargas.
- **Panel avanzado** con importar/exportar, reset y referencia de hooks.
- **SEO técnico:** Schema.org JSON-LD, breadcrumbs nativos, HTML semántico.
- **Rendimiento:** CSS nativo modular, JS condicional y deferido, lazy loading.
- **Seguridad:** sanitización, escape, nonces, capacidades.
- **Accesibilidad:** WCAG, ARIA, navegación por teclado, reduced motion.
