# CHUQUIPIONDO

**Versión actual: 1.11.0**

**Tema WordPress profesional** para [www.chuquipiondo.com](https://www.chuquipiondo.com) — Liderazgo, Gestión y Formación con propósito. ¡Juntos, sí podemos!

## Entregables

Este repositorio contiene la suite WordPress **CHUQUIPIONDO**:

- **`chuquipiondo-theme/`** — Tema padre.
- **`chuquipiondo-child/`** — Tema hijo para personalizaciones seguras.
- **`chuquipiondo-core/`** — Plugin Core.
- **`chuquipiondo-companion/`** — Plugin Companion.
- **`chuquipiondo-ai-studio/`** — Plugin de IA para edición, imágenes y publicación con SEO.

## Características principales

- Ecosistema digital: portal editorial, revista digital y plataforma musical.
- Customizer completo y cabeceras configurables.
- Hero / Slider y Home Builder modular.
- Blog editorial y layouts de entradas.
- Sistema de publicidad y social share.
- WhatsApp flotante y módulo de música.
- SEO técnico con Schema.org y breadcrumbs.
- Carga condicional de JavaScript y cache-busting de recursos.
- Seguridad mediante sanitización, nonces y capacidades de WordPress.
- AI Studio con permisos por contenido, control de publicación y manejo endurecido de secretos.

## Requisitos

- WordPress 6.2+
- PHP 7.4+

## Instalación

Comprime cada carpeta del entregable que necesites en un `.zip` y súbelo desde el administrador de WordPress, o copia las carpetas correspondientes a `wp-content/themes/` y `wp-content/plugins/`.
